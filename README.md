# 🐟 물고기 마을의 호수 — 공유지의 비극 교실 게임

학생들이 크롬북·휴대폰으로 참여하는 공유지의 비극 체험 게임이에요.

| 화면 | 주소 | 누가 보나요 |
|---|---|---|
| 선생님 조작 화면 | `/` | 선생님 노트북 (학생들이 고른 숫자가 보여요) |
| TV 화면 | `/tv?c=코드` | 확장 모니터·TV (누가 냈는지만 보여요) |
| 학생 화면 | `/s` | 학생 기기 (QR로 들어와요) |

## 규칙
- 라운드마다 학생은 물고기를 0~3마리 중에 몰래 골라요.
- 잡고 남은 물고기의 50%만큼 새끼가 태어나요 (호수 최대 100마리).
- 라운드가 끝날 때마다 살기 위해 내 물고기 1마리를 먹어요. 먹을 물고기가 없으면 탈락 — 다음 라운드에 나갈 수 없어요. (설정에서 '먹고 나서 0마리면 탈락'으로 바꿀 수 있어요)
- 호수가 텅 비면 모두의 수명 아웃 — 잡아 둔 물고기도 모두 사라져요.
- 10라운드까지 살아남으면 먹고 남은 물고기가 점수예요.
- 생존 식량(라운드마다 먹는 물고기)은 설정에서 0~3마리로 바꿀 수 있어요. 0이면 이 규칙이 꺼져요.
- 기본 설정: 1~24번, 16번 결번(23명). 선생님 화면의 설정에서 바꿀 수 있어요.

## 수업 흐름
1. 선생님 화면에서 **방 만들기** → **📺 TV 화면 열기**를 눌러 그 창을 확장 모니터로 옮기고 전체 화면(F11).
2. 학생은 TV의 QR이나 주소로 들어와 번호를 골라요.
3. **1라운드 시작** → 학생이 고르면 **결과 보기** → **다음 라운드**.
4. 끝나면 토론하고 **우리 반 약속 정하기**에서 1인당 약속 마리 수와 벌칙을 골라 **약속 지키며 다시 하기**. 학생들은 그대로 이어서 해요.

## 우리 반 약속 · 벌칙 (여러 개 선택 가능)
1. 📢 알리기 — 약속을 어긴 친구가 몇 명인지 TV에 알려요 (이름은 안 나와요)
2. ↩️ 물고기 돌려놓기 (추천) — 약속보다 더 잡은 물고기는 호수로 돌아가요
3. ⛔ 출어 금지 — 어기면 다음 1라운드 동안 못 잡아요
4. 🪜 단계적 벌칙 — 1번 경고 → 2번째부터 돌려놓기 → 3번째부터 돌려놓기 + 출어 금지
5. 🔒 어획 한도 — 약속보다 많이는 고를 수 없게 막아요

누가 어겼는지는 선생님 조작 화면에서만 보여요. TV에는 인원수만 나와요.

## Render 배포 (무료)
1. Render → **New → Web Service** → 이 저장소 연결
2. Runtime: Node · Build Command: `npm install` · Start Command: `node server.js` · Instance Type: Free
   (또는 **New → Blueprint**로 `render.yaml`을 그대로 써도 돼요)
3. 배포가 끝나면 나오는 `https://….onrender.com` 주소가 선생님 화면이에요.

## 알아 둘 점
- 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 수업 전에 선생님 화면을 한 번 열어 두면 1분 안에 깨어나요.
- 방 정보는 서버 메모리에만 있어요. 서버가 다시 시작되면 방이 사라지니 새 방을 만들어 주세요.
- 학생 실명은 쓰지 않아요 (번호 + 닉네임 선택).
- 외부 라이브러리 없이 Node 18+만으로 돌아가요. QR은 `vendor/QRCode`(Apache-2.0)로 서버에서 그려요.

로컬 실행: `node server.js` → http://localhost:3000

## 보안 · 개인정보
- 학생 실명을 받지 않아요 (번호 + 별명 선택). 별명은 10자, 특수기호는 지워져요.
- 모든 정보는 서버 메모리에만 있고, 8시간 안 쓰면 지워져요. 서버가 다시 시작되면 모두 사라져요. 파일·데이터베이스에 저장하지 않아요.
- 선생님 조작은 방을 만든 기기만 할 수 있어요 (무작위 키).
- 참여 코드는 6자리예요. TV 화면은 선생님 화면의 📺 버튼으로만 열려요 (보기용 키 필요).
- 🔓 **입장 잠그기**: 모두 들어오면 잠가 두세요. 낯선 기기는 못 들어오고, 이미 들어온 학생은 다시 연결할 수 있어요.
- TV 화면에는 학생이 고른 숫자, 학생별 모은 물고기 수, 벌칙 받은 학생 이름이 나오지 않아요.
- 서로 다른 방 코드를 계속 넣으면 잠시 막아요 (코드 맞히기 방지). 지나치게 많은 요청도 막아요.
- 보안 헤더(CSP 등)를 넣었고, 검색 엔진에 노출되지 않게 했어요.
- 접속 횟수 제한을 위해 IP 주소를 최대 10분 동안 메모리에만 기억했다가 지워요.

### 공격 점검
`tools/security-check.mjs`는 코드 맞히기, TV 엿보기, 자리 빼앗기, 연결 폭탄, CSRF, 별명 공격, 경로 조작, slowloris 등 20가지 공격을 직접 시도해 봐요.
로컬에서 `PORT=3123 node server.js`를 켠 뒤 `node tools/security-check.mjs`로 실행해요. 실제 수업 서버에는 돌리지 마세요.
