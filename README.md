# 🐟 물고기 마을의 호수 — 공유지의 비극 교실 게임

학생들이 크롬북·휴대폰으로 참여하는 공유지의 비극 체험 게임이에요.

| 화면 | 주소 | 누가 보나요 |
|---|---|---|
| 선생님 조작 화면 | `/` | 선생님 노트북 (학생들이 고른 숫자가 보여요) |
| TV 화면 | `/tv?c=코드` | 확장 모니터·TV (누가 냈는지만 보여요) |
| 학생 화면 | `/s` | 학생 기기 (QR로 들어와요) |

## 규칙
- 라운드마다 학생은 물고기를 0~3마리 중에 몰래 골라요.
- 잡고 남은 물고기의 50%만큼 새끼가 태어나요 (호수 최대 100마리).
- 호수가 텅 비면 모두의 수명 아웃 — 잡아 둔 물고기도 모두 사라져요.
- 10라운드까지 살아남으면 잡은 물고기가 점수예요.
- 기본 설정: 1~24번, 16번 결번(23명). 선생님 화면의 설정에서 바꿀 수 있어요.

## 수업 흐름
1. 선생님 화면에서 **방 만들기** → **📺 TV 화면 열기**를 눌러 그 창을 확장 모니터로 옮기고 전체 화면(F11).
2. 학생은 TV의 QR이나 주소로 들어와 번호를 골라요.
3. **1라운드 시작** → 학생이 고르면 **결과 보기** → **다음 라운드**.
4. 끝나면 토론하고 **우리 반 약속**을 적어 **약속 지키며 다시 하기**. 학생들은 그대로 이어서 해요.

## Render 배포 (무료)
1. Render → **New → Web Service** → 이 저장소 연결
2. Runtime: Node · Build Command: `npm install` · Start Command: `node server.js` · Instance Type: Free
   (또는 **New → Blueprint**로 `render.yaml`을 그대로 써도 돼요)
3. 배포가 끝나면 나오는 `https://….onrender.com` 주소가 선생님 화면이에요.

## 알아 둘 점
- 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 수업 전에 선생님 화면을 한 번 열어 두면 1분 안에 깨어나요.
- 방 정보는 서버 메모리에만 있어요. 서버가 다시 시작되면 방이 사라지니 새 방을 만들어 주세요.
- 학생 실명은 쓰지 않아요 (번호 + 닉네임 선택).
- 외부 라이브러리 없이 Node 18+만으로 돌아가요. QR은 `vendor/QRCode`(Apache-2.0)로 서버에서 그려요.

로컬 실행: `node server.js` → http://localhost:3000
